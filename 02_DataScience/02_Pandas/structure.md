# Learning Phases

## Phase 1 — Beginner Level

Topics:
- Series
- DataFrame
- Indexing
- CSV/JSON
- Data Selection
- Filtering
- Sorting

Goal:
Understand Pandas fundamentals and syntax.

---

## Phase 2 — Intermediate Level

Topics:
- Missing Values
- Duplicates
- String Operations
- DateTime Handling
- Data Cleaning
- GroupBy
- Merge & Join

Goal:
Learn real-world preprocessing and analysis.

---

## Phase 3 — Advanced Level

Topics:
- MultiIndex
- Pivot Tables
- Window Functions
- Performance Optimization
- Large Dataset Handling

Goal:
Industry-level data handling.

---

## Phase 4 — EDA & ML Preparation

Topics:
- Exploratory Data Analysis
- Feature Engineering
- Statistical Analysis
- Data Transformation

Goal:
Prepare datasets for Machine Learning.
